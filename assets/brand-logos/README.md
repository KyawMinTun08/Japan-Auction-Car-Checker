# JACC Brand Logo Assets

These SVG files are local, optimized single-color brand marks used by the JACC dashboard brand-card UI. They were retrieved from the Simple Icons CDN during the 2026-08-16 implementation and are stored locally so the dashboard does not depend on a third-party request at runtime.

Source: https://cdn.simpleicons.org/

Brand names and marks remain the property of their respective owners. The assets are used only as identifying labels for vehicle makes inside the JACC car-data interface.
